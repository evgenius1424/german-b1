# Hören design notes

Useful B1 listening practice tests comprehension of distinctions, not rare vocabulary. Strong items create a plausible competing fact and ask the listener to resolve a specific semantic slot: who acted, what changed, when something happens, where it occurs, why it matters, or which speaker holds a view.

Common distractor patterns include an earlier plan replaced by the actual outcome, a quoted opinion attributed to the wrong speaker, a condition mistaken for a result, and a keyword match that reverses the intended meaning. The generator encodes these patterns in its blueprint so exam variety is deliberate rather than accidental.

For text that will be spoken by TTS, use clear standard German, short turns, written-out abbreviations, and neutral punctuation. Avoid stage directions, expressive interjections, emoji, and theatrical punctuation because they distort synthetic delivery.
